# Message pro

Même but que Logyc : une pensée désorganisée devient un document clair. Le livrable est le message, prêt à envoyer.

## Étapes

1. Repérer destinataire, demande, délai, et ce qui doit rester confidentiel. Si le destinataire manque, laisser un champ `[Prénom]` plutôt que d'inventer un nom.
2. Écrire en français, sauf si les notes sont en anglais ou si la personne le demande.
3. Produire une version seule :
   - objet (une ligne, concret)
   - 3 à 6 phrases, ou une courte liste si la note est une liste de tâches
   - une seule action demandée à la fin
4. Garder les faits des notes. Ne pas ajouter de promesses, de chiffres, ou de contexte qui n'y sont pas.
5. Ton : direct, poli, sans formule creuse (« je me permets de », « n'hésitez pas », « j'espère que vous allez bien »). Tutoiement seulement si les notes tutoient déjà.

## Sortie

Coller le message final en premier. En dessous, au plus trois choix ouverts (destinataire, ton, pièce jointe) s'il en manque vraiment un.
